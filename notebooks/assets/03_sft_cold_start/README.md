# Notebook 03 assets

- `sft_workflow.png` and `.svg`: conceptual reference-solution supervised training.
- `response_mask.png` and `.svg`: illustrative prompt/response/end/padding labels.
- `VALIDATION.md`: evidence boundaries and reproducible commands.
- `validation_summary.json`: recorded local QA results, not a model benchmark.

Regenerate artwork with `python scripts/render_project_assets.py`. These diagrams
contain no fabricated training measurements. Real charts are created only in a
completed training run and stored with that run under ignored `results/`.
